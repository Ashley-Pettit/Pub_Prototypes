## Prototypes

- [Roster Builder](https://ashley-pettit.github.io/Pub_Prototypes/roster-builder/): rapid prototype, not an endorsed tool. Builds and checks a team roster, then hands it over as an Excel file that becomes the source of truth. Synthetic data only.
- [AI Champions Training](https://ashley-pettit.github.io/Pub_Prototypes/ai-course/): draft training prototype, not endorsed. A hands-on Agent Builder course for AI Champions: building agents, knowledge, testing and keeping information safe.
