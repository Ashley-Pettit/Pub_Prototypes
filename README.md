# Rapid AI prototypes for manager review

Live hub: https://ashley-pettit.github.io/logan-prototypes/

Early concepts built quickly with AI. Not endorsed tools. Synthetic data only.

## Prototypes

- [Roster Builder](https://ashley-pettit.github.io/logan-prototypes/roster-builder/): rapid prototype, not an endorsed tool. Builds and checks a team roster, then hands it over as an Excel file that becomes the source of truth. Synthetic data only.
- [AI Champions Training](https://ashley-pettit.github.io/logan-prototypes/ai-course/): rapid prototype, not an endorsed course. For management review. A hands-on Agent Builder course for AI Champions: building agents, knowledge, testing and keeping information safe.
